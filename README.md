# Toxic Chat Detection

NLP based toxic and non-toxic chat message classification system.

## Project Overview

This project aims to classify player chat messages as toxic or non-toxic using transformer-based NLP models. The system is designed for online gaming environments and focuses on detecting harmful, abusive, and offensive messages.

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Pandas
- NumPy
- Scikit-Learn

## Models Evaluated

- BERT
- DistilBERT
- RoBERTa
- DeBERTa

## Features

- Data preprocessing
- Text tokenization
- Model training
- Hyperparameter optimization
- Model evaluation
- Overfitting analysis
- Toxicity prediction

## Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Dataset

The project was trained using multiple toxic speech, gaming chat, and sarcasm datasets. Data cleaning and preprocessing techniques were applied to improve model performance.

## Future Improvements

- Sarcasm detection
- Context-aware toxicity detection
- Real-time chat moderation
- Multi-language support
- Web and mobile deployment
