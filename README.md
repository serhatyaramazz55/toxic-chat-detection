# Toxic Chat Detection

A Natural Language Processing project developed to detect toxic and non-toxic messages in online game chats.

## Project Overview

This project aims to classify player chat messages as toxic or non-toxic using transformer-based NLP models.

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Pandas
- NumPy
- Scikit-Learn

## Models Evaluated

- BERT
- DistilBERT
- RoBERTa
- DeBERTa

## Features

- Data preprocessing
- Tokenization
- Hyperparameter optimization
- Model evaluation
- Overfitting analysis
- Toxicity prediction

## Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
