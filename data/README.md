# Data

The notebook expects the source datasets to be supplied locally/through Google Colab.

Expected input filenames used by the notebook include:

- `CONDA_train.csv`
- `CONDA_valid.csv`
- `train.csv` (Jigsaw toxicity dataset format)
- `english_gaming_sarcasm_toxic_dataset_10000.csv`
- `english_gaming_family_sarcasm_contrast_5000.csv`

Dataset files are not included in this repository. Update the paths in the notebook if your files are stored elsewhere.
